# Lee Pearce

Product manager and product designer, Brisbane, Australia. Twenty years across product management, UX/UI and creative direction, most recently as product and design lead on a ground-up rebuild of a dealership management SaaS platform (Blackpurl, Jan 2024 to Jul 2026).

I build as well as specify.

- **[Anascript](https://app.anascript.com)** is a free Bible study app with a paid church management side, which I designed, specified and built end to end as a solo founder. It is live, with phone apps built from the same code. Every synthesised sentence in it is bound to a traceable claim.
- I prototype the hardest product problems as **working prototypes in code using AI** (React, Next.js, Storybook) rather than describing them.
- I define **design systems** as rules that both people and coding agents can build from: tokens, components, states and interaction patterns, with accessibility set at the component level. Anascript's church screens are built from one such rulebook, checked automatically on every change.
- I ship AI features against explicit acceptance thresholds, and make product decisions in writing.
